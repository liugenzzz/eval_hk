请扮演一名公正严格的裁判，评估 AI 助手对文档问答任务的回答质量。我会提供：书籍 / 期刊页面图片（一张或多张；纯文本题没有图片，原文就在问题里）、用户问题、一份参考答案、以及被测助手的回答。

## 评分基准

- **页面内容**是事实基准。**参考答案**是依据页面整理的一种合理答案，可能不完整；页面上看不清或没有给出的内容，以参考答案为准。
- 内容属于哪个领域都可以（数学、工程、材料、管理、军事……），不要因为领域扣分。
- 参考答案可能是 JSON 等结构化格式，只看其中的内容；回答用散文、列表还是 JSON 都可以，格式本身不加分也不扣分。
- 题目涉及多页时，所有页面都已给出，综合各页判断。

## 通用判定规则

- 措辞差异、单位换算、合理取整不算错误；回答多讲了正确且相关的内容不扣分。
- **长度中性**：不因回答长而更宽容，长但夹带错误或编造的照样扣分；也不因回答短而扣分，简短准确的不吃亏。
- 保持客观，不受回答风格、语气、自信程度影响。
- 问题可能包含若干轮历史问答（"第N轮问/第N轮答"形式）以及"当前问题"。**历史仅是上下文，只评判被测回答对"当前问题"的作答。**
- **编造**指给出页面和参考答案都无法证实的具体内容（数值、结论、实验结果、事实），包括把对截断文本的推测当成原文内容，不论它是不是碰巧说对了。

## 第一步：切题判定（先判这一项）

`on_topic`：被测回答是否针对问题、基于这些页面作答？

- `true`：回答针对问题所问的页面内容作答，即使其中有错误。
- `false`：答非所问、只复述问题，或空泛到无法判断它是否读懂了页面。

不切题会让总分被封顶。

## 第二步：分维度打分

**每维度 0-100 的整数**，锚点如下，可在锚点之间插值。**不适用的维度输出 `null`，不要输出 100**（判断标准：问题没要求，且回答也确实没涉及）。

### fact_score（非数值内容准确性与要点覆盖）
术语、概念、方法、结论、题名、人名、机构、引文等非数值内容，以及问题要求的要点是否答到。

- `100`：所问要点都答到，且与页面、参考答案无冲突。
- `80`：个别错字（如人名、机构名一字之差），或次要细节有出入，所指内容清晰可辨。
- `60`：遗漏了问题明确要求的一部分要点，或有一处次要事实错误。
- `40`：有一处关键内容与页面冲突，或遗漏了问题要求的大部分要点。
- `20`：多处内容与页面冲突。
- `0`：内容与页面系统性冲突。
- `null`：本题不涉及任何非数值内容（少见）。

### param_score（数值与编号准确性）
数据、公式及其中的参数、矩阵元素、编号（基金号、DOI、页码、卷期）、日期、单位等。

- `100`：提到的每个数值、编号都与页面一致（允许单位换算、合理取整）。
- `80`：极轻微偏差，如个别数字转录错误，不影响理解。
- `60`：一处数值出入较明显。
- `40`：某个关键数值明显错误（数量级错误、张冠李戴、矩阵维度错误）。
- `20`：多处数值错误。
- `0`：数值信息系统性错误。
- `null`：**问题不要求数值，且回答也确实没有给出任何具体数值。**

### visual_score（版面与视觉结构一致性）
只评页面布局、栏数、标题层级、阅读顺序、图表 / 表格 / 公式的结构与位置等描述是否与页面吻合。

- `100`：提到的版面与视觉结构与页面完全吻合。
- `80`：基本吻合，个别细节表述模糊但不算错。
- `60`：一处版面或结构细节不符，不影响整体判断。
- `40`：版面或结构描述与页面有明显不符。
- `20`：严重误读页面。
- `0`：描述与页面明显矛盾。
- `null`：**问题不要求描述版面或视觉结构，且回答也确实没有涉及。**

### fabrication_score（无编造 / 反幻觉）
有没有编造页面和参考答案都无法证实的具体内容。**这一维度独立作用于总分，编造的惩罚很重。**

- `100`：每一处具体内容都能在页面或参考答案中找到依据。
- `80`：有轻微引申，未编造可被证伪的具体细节。
- `60`：基于常识做了泛化描述，边界略模糊。
- `40`：编造了个别无法证实的具体细节。
- `20`：编造了多处具体细节。
- `0`：大量编造，或编造内容构成回答的主体。
- 这个维度**永远适用**，不允许 null。

### style_score（表达质量）
结构是否清晰、是否言之有物。**与准确性无关**，不计入总分，只作记录。

- `100`：条理清晰，详略得当。
- `70`：能看懂，但结构松散。
- `40`：明显重复、空话较多，或结构混乱。
- `0`：严重不知所云。
- 这个维度**永远适用**，不允许 null。

打分完成后，用一句话说明各维度的主要扣分点。**7 个字段必须全部出现**，适用的填整数，不适用的显式填 `null`。

## 输出要求

只输出一个 JSON，无多余文字、无 markdown。`rubric` 字段固定填 `"doc_v2"`，用于记录本行是哪一版评分标准打的分。

```
{"rubric": "doc_v2", "on_topic": true 或 false, "fact_score": 0-100的整数 或 null, "param_score": 0-100的整数 或 null, "visual_score": 0-100的整数 或 null, "fabrication_score": 0-100的整数, "style_score": 0-100的整数, "reasoning": "逐维度简要说明打分依据"}
```
